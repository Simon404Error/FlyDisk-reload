# FlyDisk（个人修改版）

> 上游项目：[youke1686/FlyDisk](https://github.com/youke1686/FlyDisk)。本仓库是它的**个人 fork**，用于自用改进与试验，
> 修改点见下；上游功能说明与跑分实测请看上游 README。

Windows 机械硬盘块级缓存加速器：点「启动加速」后，程序把目标 HDD **整盘脱机 + 独占打开**，
再用本机回环 iSCSI 目标把这块盘重新暴露给 Windows（盘符照常回来），读写先经过
**L1 内存缓存 + L2 硬盘缓存（推荐 SSD）** 两层。

> ⚠ **处于 Beta 阶段，请勿用于重要数据**。程序必须**以管理员身份运行**（整盘脱机与独占打开需要）。
> 停止加速后目标盘**保持脱机、在系统里看不到**——这是有意设计；要还盘给系统走菜单「重新联机硬盘」。

## 本 fork 相对上游的改动

- **多盘同时加速**：「启动加速」的选盘框可**多选**，多块盘同时接管。每块盘各用各的 iSCSI 端口（从配置端口依次递增）
  与各自的 IQN，互不干扰；**逐块独立成败**（一块失败不影响其它块，日志汇总"成功 N/M"）；
  主按钮变「停止加速（全部 N 块）」一键收尾。**L2 只作用于第一块盘**（一份 L2 容器只能属于一块盘），其余盘仅 L1 + 写透传。
- **开机自启动**：用**计划任务**实现（用户登录时触发 + 最高权限），**不弹 UAC**。
  不用注册表 Run 键——本程序是管理员程序，那种方式每次开机都会弹一次 UAC。
- **开机保持脱机**：可在设置里指定「开机目标盘」，开机时（**含未登录**）由 `FlyDisk.exe --keep-offline-only`
  短暂执行一次：把这些盘整盘脱机后**立刻退出**（脱机属性是持久化的，进程退出后盘仍保持脱机），
  避免被系统或其它程序占用而无法加速。目标盘按**设备身份串**（型号|序列号）保存，换盘符/换接口都不影响；
  设置里既能多选，也能**按盘符添加**（例如输入 `Y,Z`）。
- **界面**：窗口可自由拖动改变大小；日志框加高、底部贴近软件底端；新增「清空日志」按钮（只清界面，不动诊断日志）；
  标题栏显示版本号；移除右下角的「求 star」提示与徽标。
- **磁盘句柄健壮性**：改磁盘属性与独占打开前的共享模式放宽、独占打开带重试与静默期，
  避免"错误 32：另一个程序正在使用此文件"这类失败。
- 涉及的主要源文件：`StartupService.cs`、`BootDiskPreparation.cs`、`Form1.cs`、`Settings.cs`、`PickerForm.cs`、
  `Engine/PhysicalDiskHandle.cs`、`Engine/TargetService.cs`。

## 使用要点

1. 以管理员身份运行 `FlyDisk.exe`（UAC 点「是」）。
2. 点「启动加速」→ 选一块或**多块**盘 → 确定；日志区会打印进度（通常几秒）。
3. 停止：点「停止加速（全部 N 块）」；关机时程序会自动收尾（落 L2 账本、盘保持脱机）。
4. 想开机自动把目标盘保持脱机：菜单「设置」→「开机与自动化」勾选并选择硬盘（可多选或按盘符添加）。
5. 加速收益取决于**访问是否有热点**：反复读同一批文件最明显；全盘顺序读写收益有限。

## 构建

需要 .NET 10 SDK：

```cmd
dotnet publish FlyDisk\FlyDisk.csproj -c Release -r win-x64
```

产物：`FlyDisk\bin\Release\net10.0-windows\win-x64\publish\FlyDisk.exe`（程序名不带版号，版号显示在标题栏）。
