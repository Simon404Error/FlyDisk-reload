## 本 fork 相对上游的改动

- **多盘同时加速**：支持对多个磁盘进行加速，仅适用 L1，暂时不支持 L2
- **开机自启动**：用**计划任务**实现（用户登录时触发 + 最高权限），**不弹 UAC**
- **开机保持脱机**：在设置菜单里
- **界面**：窗口可自由拖动改变大小；新增「清空日志」按钮（只清界面，不动诊断日志）；标题栏显示版本号
- **磁盘句柄健壮性**：改磁盘属性与独占打开前的共享模式放宽、独占打开带重试与静默期，避免"错误 32：另一个程序正在使用此文件"这类失败

## 使用要点

1. 以管理员身份运行 `FlyDisk.exe`（UAC 点「是」）。
2. 点「启动加速」→ 选一块或**多块**盘 → 确定；日志区会打印进度（通常几秒）。
3. 停止：点「停止加速（全部 N 块）」；关机时程序会自动收尾（落 L2 账本、盘保持脱机）。
4. 想开机自动把目标盘保持脱机：菜单「设置」→「开机与自动化」勾选并选择硬盘（可多选或按盘符添加）。
5. 加速收益取决于**访问是否有热点**：反复读同一批文件最明显；全盘顺序读写收益有限。

## 构建

需要 .NET 10 SDK：

```cmd
dotnet publish FlyDisk\FlyDisk.csproj -c Release -r win-x64
```

产物：`FlyDisk\bin\Release\net10.0-windows\win-x64\publish\FlyDisk.exe`（程序名不带版号，版号显示在标题栏）。
